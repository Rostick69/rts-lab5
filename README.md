# Системы массового обслуживания и надёжность

Практическая работа № 5. Вариант 2 — пул процессоров с общей очередью FIFO.

Запуск из корня репозитория на Python 3.10 или новее:

```console
python src/main.py
python src/main.py data/control.csv
```

Внешние библиотеки не требуются. По умолчанию используется `data/variant2.csv`.
CSV содержит одну строку данных. Поля `lam` и `mu` измеряются в заявках/с,
`n` — число процессоров, `deadline` — порог ожидания в секундах,
`mtbf` и `mttr` — наработка и время восстановления узла в часах.

Программа сравнивает один процессор с пулом, проверяет устойчивость и выводит
вероятность ожидания дольше заданного порога. Готовность рассчитывается отдельно
для всего узла. Отчёт с алгоритмом, результатами и листингом находится в `docs/`.
